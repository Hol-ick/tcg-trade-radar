# 3개월 거래 수집 스냅샷

- 조회 기간: 2026-05-13 ~ 2026-08-13
- 대상: 유희왕, 원피스 카드게임, 포켓몬 카드게임, 디지몬 카드게임, 뱅가드
- 수집 범위: 판매·구매·거래 게시글, 거래 행, 댓글, 수집 로그
- 생성 시점: `manifest.json`의 `generated_at` 참조

## 파일

- `posts.csv`: 게시글·작성자·판매자 분석·재게시 정보
- `listings.csv`: 카드명·가격·수량·배송비·거래 유형·전처리 상태
- `comments.csv`: 댓글 작성자·유형·본문·게시 시각
- `logs.jsonl`: 작업별 목록/게시글/댓글 처리 로그
- `manifest.json`: 작업 ID·상태·파일별 건수·스냅샷 정보

원문 HTML은 로컬 감사용 SQLite에 보존하고 공개 데이터셋에는 포함하지 않습니다. 원문을 포함한 전체 DB는 GitHub 일반 파일로 관리하기에 크기가 크고, 게시글에 포함된 연락처·외부 링크 같은 정보가 그대로 공개될 수 있기 때문입니다.
